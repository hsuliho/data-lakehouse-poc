# 5. 边界接口 (Boundary Interfaces)

## 1. 对外接口与集成清单

本系统向外部用户、编排系统、BI 工具及治理平台暴露了标准化、多层次的边界接口：

| 接口类型 | 访问入口 / 路径 | 核心协议与用途 |
| :--- | :--- | :--- |
| **CLI 命令行接口** | `python -m agent.cli`<br/>`python scripts/load.py`<br/>`python scripts/scd2.py` | 供开发者与运维人员进行 AI 代理交互、数据加载与 SCD2 手动触发 |
| **编排接口** | `orchestration/definitions.py`<br/>Dagster Webserver (默认 3000 端口) | 声明式定义资产、作业与传感器，提供可视化的流水线调度与监控 |
| **SQL 数据库接口** | Trino 协调节点 (默认 8080 端口)<br/>Python Trino Client (`trino==0.339.0`) | 提供高性能、标准的 ANSI SQL 查询与分布式湖仓访问 |
| **语义层接口** | `dbt_semantic/` (MetricFlow CLI / API) | 提供结构化、无歧义的业务指标查询接口 |
| **元数据与 BI 接口** | `datahub/` (Ingestion Recipes)<br/>Superset (`superset_setup.py`) | 提供企业级元数据血缘治理、PII 标签同步与 BI 可视化仪表盘 |

---

## 2. 安全与访问控制边界

- **Trino 访问控制**: 位于 `trino/rules.json` 与 `trino/access-control.properties`，实现细粒度的行级与列级安全策略（Row & Column-level Security），确保 PII 敏感信息在查询时自动脱敏。
